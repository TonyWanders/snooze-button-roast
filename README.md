## The entry

> Saturday, 6 AM: my alarm clock goes off like a toddler with a drum kit, no rhythm, no mercy, and somehow convinced it's a gift.

One line, 127 characters. It roasts an alarm clock for ringing at 6 AM on a
Saturday morning, as the brief asks.

## How it works

`main.py` is deterministic: it writes the entry above, byte for byte, to
`/output/entry.txt` and prints the same line to stdout. No input, no
randomness, no network, no clock, so repeated runs produce identical output.

Run it:

```sh
python3 main.py
```
